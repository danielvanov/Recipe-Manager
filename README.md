# Recipe Manager

## Описание
Recipe Manager е конзолно C++ приложение за управление на рецепти. Проектът е направен като задача по Обектно-ориентирано програмиране и демонстрира класове, наследяване, капсулация, полиморфизъм и работа с файлове.

## Избрана тема
Кулинарен помощник / Recipe Manager.

## Планирани функционалности
1. Добавяне на рецепта.
2. Показване на всички рецепти.
3. Търсене на рецепта по име.
4. Изтриване на рецепта по id.
5. Оценяване на рецепта.
6. Филтриране по трудност.
7. Филтриране по категория.
8. Сортиране по време за приготвяне.
9. Сортиране по рейтинг.
10. Запазване на рецепти във файл.
11. Зареждане на рецепти от файл.
12. Показване на детайли за рецепта.
13. Добавяне на примерни рецепти.

## Класова йерархия
- `BaseEntity`: базов клас с id.
- `Ingredient`: представлява съставка на рецепта.
- `Recipe`: основен клас за рецепти, наследява BaseEntity.
- `DessertRecipe`: специализиран десерт, наследява Recipe.
- `MainDishRecipe`: основно ястие, наследява Recipe.
- `RecipeManager`: управлява колекцията от рецепти.
- `FileManager`: записва и зарежда рецепти от файл.
- `Menu`: показва менюто и обработва потребителския вход.

## Обосновка на дизайн решения
1. Recipe наследява BaseEntity, защото всяка рецепта има уникален идентификатор.
2. DessertRecipe и MainDishRecipe наследяват Recipe, защото са специализирани видове рецепти с допълнителна информация.
3. Полетата са private или protected, за да се запази капсулация и да не се променят директно отвън.
4. displayInfo() е virtual, защото различните видове рецепти показват различна информация.
5. RecipeManager управлява колекцията от рецепти, за да не се смесва логиката за управление със самия модел Recipe.
6. FileManager е отделен клас, защото записването и зареждането от файл са отделна отговорност.
7. RecipeManager използва vector<Recipe*>, за да може да съхранява различни наследници на Recipe и да демонстрира полиморфизъм.

## Компилация
```bash
g++ main.cpp BaseEntity.cpp Ingredient.cpp Recipe.cpp DessertRecipe.cpp MainDishRecipe.cpp RecipeManager.cpp Menu.cpp FileManager.cpp -o recipe-manager
```

## Стартиране


```bash

```
